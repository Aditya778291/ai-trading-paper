# V1.5 production notes

- Keep the event loop enabled only for paper-trading portfolios until broker integration is separately designed and approved.
- Run the loop as a dedicated worker/process in production; do not depend on multiple API replicas each running their own monitor.
- Use Redis/job locking when horizontally scaling the monitor so one portfolio is not processed twice per cycle.
- Configure quote TTL/polling to respect the upstream market-data provider's limits.
- Treat stale or unavailable quotes as a no-action condition; never force an exit using an old price.
- Persist stop-loss/take-profit levels through Alembic migration `0002_live_risk_levels`.
