# V1.2 Production Infrastructure

1. Run PostgreSQL and Redis (the included Compose file does both).
2. Set `DATABASE_URL`, `REDIS_URL`, a strong `JWT_SECRET`, `ENVIRONMENT=production`, and explicit `ALLOWED_ORIGINS`.
3. Run `alembic upgrade head` before starting API workers.
4. Put TLS termination/API gateway in front of Uvicorn.
5. Use Redis for shared rate limiting and queued notification jobs.
6. Export `/api/metrics` to your monitoring system; add external logs/traces at the gateway.
7. Back up PostgreSQL and test restore procedures.
8. Keep broker execution disabled: this application remains paper-trading/research only.
