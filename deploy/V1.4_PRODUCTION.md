# V1.4 Production Notes

V1.4 adds a market-data adapter and live paper-trading workflow. Quotes are fetched from Yahoo Finance through `yfinance`, cached briefly, and used only to simulate paper fills. **No broker order is submitted.**

## API
- `GET /api/market/quote/{symbol}` — latest cached/polled quote
- `GET /api/market/quotes?symbols=RELIANCE.NS,TCS.NS` — batch quotes
- `POST /api/orders/market` — paper-fill an order at the latest quote
- `POST /api/portfolio/mark-to-market` — refresh open-position prices
- `GET /api/portfolio` — now marks the portfolio to market before returning equity

## Production considerations
- Yahoo Finance is not a guaranteed exchange-grade feed. For production/live trading, replace `src/api/market_data.py` with a licensed broker/exchange feed adapter.
- Keep paper-only behavior until a separately audited execution adapter exists.
- Use a bounded polling cadence and monitor quote failures/staleness.
- Run the API behind TLS and keep Redis/PostgreSQL configured as in V1.3.
