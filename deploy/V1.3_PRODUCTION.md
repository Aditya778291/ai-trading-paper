# V1.3 Production Readiness

- API: FastAPI with JSON request logs, request IDs, latency metrics, readiness, and Prometheus-compatible counters.
- Queue worker: Redis-backed notification jobs are consumed by `python -m src.api.worker`; local fallback remains for development.
- Mobile: Expo/React Native reference client under `mobile/`.
- Database: PostgreSQL is the production target; run `alembic upgrade head` before deployment.
- Secrets: use environment/secret-manager values for `JWT_SECRET`, `POSTGRES_PASSWORD`, and provider credentials. Never commit `.env`.
- TLS: terminate HTTPS at a reverse proxy/load balancer and restrict CORS to known origins.
- Monitoring: scrape `/api/metrics/prometheus` with an authenticated monitoring identity or expose it only through a trusted internal network.
- Push notifications: provider integration is intentionally left as a deployment concern; the API emits notification jobs without embedding credentials.
- Paper-only safety: no broker execution path is included.
